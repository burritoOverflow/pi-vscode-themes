# Pi VSCode Themes

Themes ported from VSCode themes for [pi coding agent](https://github.com/badlogic/pi-mono).

[Tsoding Gruber Minimal](https://github.com/AnksioXD/Tsoding-Gruber-Minimal-For-VSCode/tree/main), all three included themes.

[Warm Burnout Dark](https://github.com/felipefdl/warm-burnout), the dark VSCode theme.

install via `pi`

```bash
pi install git:github.com/burritoOverflow/pi-vscode-themes
```
